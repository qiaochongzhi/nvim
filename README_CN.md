# 🧠 Neovim 配置（Lua + Lazy.nvim）

一个面向 **科研（统计物理 / 分子模拟）+ 编程** 的 Neovim 配置。

## ✨ 功能特性

### 🧩 核心功能
- lazy.nvim
- 原生 LSP
- nvim-cmp
- LuaSnip
- telescope.nvim
- which-key.nvim

### 🖥 UI
- tokyonight
- lualine

### ✍️ 编辑增强
- nvim-autopairs
- Comment.nvim
- nvim-surround
- undotree

### 🔬 科研支持
- vimtex
- markdown-preview
- 自定义 snippet

## 🚀 安装

```bash
git clone https://github.com/<your-username>/nvim ~/.config/nvim
nvim
```

## 📂 结构

```
init.lua
lua/
lazy-lock.json
```
